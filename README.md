# Multilingual Language Learning Chatbot

This project is a real-time, multilingual language learning chatbot built with OpenAI GPT-3.5, LangChain, Gradio, and SQLite. It helps users practice conversations in any language and provides feedback on grammar mistakes.

## Features
- Multilingual support
- Real-world scenario-based learning
- Mistake detection and correction
- Mistake logging with SQLite
- Hugging Face Spaces deployment
- Secure API handling via environment secrets

## Deployment
The app is deployed on Hugging Face using Gradio.

## Files Included
- `app.py` – Main application file
- `requirements.txt` – Python dependencies
